# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through [GitHub Security Advisories](https://github.com/joboyx/obsidian-sync-gate/security/advisories/new). Include:

- The plugin version and the app version.
- The platform (desktop or mobile, and the operating system).
- Steps to reproduce the problem.
- The effect you see, for example data loss or a bypass of the lock.

This is a volunteer project. The maintainer tries to reply within 14 days. When a fix is ready, the advisory is published with the release that contains the fix.
